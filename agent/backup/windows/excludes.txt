# Default exclusions for the MSP backup agent (restic exclude-file syntax; one pattern per line; ASCII only).
# Goal: everything a person or application would need to get their DATA back, nothing that is only the operating system,
# installed programs, caches or scratch space. This is NOT a bare-metal image: it cannot rebuild the OS.
# !! A literal "$" MUST be written as the character class [$]. restic expands $NAME as an environment variable inside
# !! exclude files, so a bare "$WinREAgent" becomes "" and the rule "**/" silently excludes EVERYTHING (found in testing).
# Site-specific additions go in agent/backup/windows/excludes.site/<customer>-<site>.txt (appended by the builder).
